# Curry Dog Codex Pet

Custom Codex pet package for Curry Dog.

## Install

1. Download `curry-dog.zip`.
2. Extract it.
3. Move the extracted `curry-dog` folder to your Codex pets folder:
   - Windows: `%USERPROFILE%\.codex\pets\curry-dog`
   - macOS/Linux: `~/.codex/pets/curry-dog`
4. Restart Codex or reopen the pet selector.

The package contains:

- `pet.json`
- `spritesheet.webp`
